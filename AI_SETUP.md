# AI Ассистент - Инструкция по настройке

## 📌 Как это работает

На вашем сайте интегрирован **бесплатный ИИ ассистент** с поддержкой двух режимов:

### Режим 1: Ollama (Локальный - Рекомендуется ✅)
- **Преимущества**: Быстро, без ограничений, полностью локально
- **Требования**: Установленный Ollama на компьютере
- **Модель**: Mistral 7B

### Режим 2: Hugging Face (Облачный - Fallback)
- **Преимущества**: Работает везде, не нужна установка
- **Ограничения**: Ограниченное количество запросов в день
- **Модель**: Llama 2 7B Chat

## 🚀 Быстрый старт

### Вариант А: С Ollama (Локально)

1. **Скачайте Ollama**: https://ollama.ai
2. **Установите**:
   - Windows: Запустите установщик
   - macOS: Нажмите на загруженный файл
   - Linux: `curl https://ollama.ai/install.sh | sh`

3. **Запустите модель**:
   ```bash
   ollama run mistral
   ```
   Ollama автоматически скачает модель (~4GB) и запустится на `http://localhost:11434`

4. **Откройте сайт**:
   - Перейдите на страницу [ai-assistant.html](ai-assistant.html)
   - AI автоматически подключится и покажет статус "✅ Ollama подключен"

5. **Начните писать**:
   - Вводите вопросы про Python
   - Получайте ответы от ИИ

### Вариант Б: Без установки (Облако)

1. **Просто откройте** [ai-assistant.html](ai-assistant.html)
2. AI автоматически переключится на Hugging Face
3. Статус покажет "✅ Онлайн режим (Hugging Face)"
4. Начните писать вопросы!

## 🔧 Проблемы и решения

### ❌ "Соединение установляется..." очень долго

**Решение 1**: Установите Ollama
- Если не установлен, AI будет ждать 10 сек перед переключением на облако

**Решение 2**: Проверьте интернет
- Убедитесь, что у вас есть соединение для облачного режима

### ❌ Ollama установлен, но AI не подключается

**Решение**:
1. Проверьте, что Ollama запущена:
   - Задайте команду: `ollama list`
   - Модель Mistral должна быть в списке
   
2. Убедитесь, что Mistral запущена:
   ```bash
   ollama run mistral
   ```

3. Проверьте, что API слушает порт 11434:
   - Откройте в браузере: `http://localhost:11434/api/tags`
   - Вы должны увидеть JSON с информацией о моделях

### ❌ "Ошибка: не смог обработать запрос"

- Это может быть timeout от облака
- Установите Ollama для более стабильной работы
- Или подождите и попробуйте снова
