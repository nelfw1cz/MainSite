# 🚀 Quick Start Guide

## What's New
Your site now has 4 new sections + AI Assistant

## How to Use

### 1. Blog
Click **📝 Блог** → Write and share articles

### 2. Resources  
Click **📚 Ресурсы** → Browse learning materials

### 3. English
Click in menu → Learn programming vocabulary

### 4. Quiz Game
Click game icon → Answer Python questions (3 levels)

### 5. AI Assistant
Click **🤖 AI** → Ask questions about Python

## AI Setup (Optional but Recommended)

### For Fast Local AI:
1. Download Ollama: https://ollama.ai
2. Install and run: `ollama run mistral`
3. Open site - AI will auto-connect

### For Cloud Mode (Works Immediately):
- Just open the site, AI uses Hugging Face automatically
